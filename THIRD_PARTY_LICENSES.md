# Third-party components

The Windows build of Valorant Aim Trainer bundles the following open-source components.
All of them are used unmodified.

| Component | Used for | License |
|---|---|---|
| [pygame-ce](https://github.com/pygame-community/pygame-ce) | window, drawing, input | LGPL-2.1 |
| [SDL2](https://www.libsdl.org/) (via pygame-ce) | window and input backend | zlib |
| [NumPy](https://numpy.org/) | analysis of training data | BSD-3-Clause |
| [Python](https://www.python.org/) runtime | program runtime | PSF License |
| [Nuitka](https://nuitka.net/) runtime | compiles the program to a native executable | Apache-2.0 |
| [Inno Setup](https://jrsoftware.org/isinfo.php) | installer / uninstaller | Inno Setup License (permissive, source available) |
